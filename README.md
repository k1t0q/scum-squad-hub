# 4.0.4 | SCUM SQUAD HUB — v2.1 RESTORED

Восстановленная по сохранённой переписке версия общего штаба SCUM-отряда.

## Реализовано
- четыре исходных раздела: **Сегодня / Операции / Задачи / Состав**;
- отметка «Буду / Под вопросом / Без меня» и времени захода;
- профиль: ник и роль;
- ручное создание задач: количество, место, приоритет, срок, ответственный, комментарий;
- задачи без количества;
- «Беру на себя»;
- совместная модель вкладов: добавление количества, суммарный прогресс;
- история вкладов и отмена ошибочного вклада;
- статусы задач;
- создание операций, время сбора, участники, заметка;
- карточка подготовки к вылазке;
- адаптивный интерфейс ПК/телефон.

## Важно
Текущая GitHub-версия хранит данные в localStorage, поэтому это функциональный прототип. В исходной задумке данные должны быть общими для всего отряда.

## Следующий этап — v2.2 ONLINE
- Supabase;
- создание отряда и код приглашения;
- лидер / администратор / участник;
- общая синхронизация состава, задач, вкладов и операций;
- доступ к чувствительным данным по разрешениям лидера.

Дальнейшие идеи из исходной переписки: запасы базы, карта отряда, журнал разведки, транспорт, наборы снаряжения и отдельная Windows overlay-панель.
